Мини‑курс Python

Теория + практика в одном файле. Подходит для старта.

Старт: что это и как пользоваться

Это мини‑аналог учебного курса: теория, примеры, задачи и проверка кода. Всё в одном файле — просто сохрани как index.html и открой в браузере.

Важно: в браузере нельзя запустить настоящий Python. Проверка задач — по ключевым словам. Для реальной проверки используй локальный интерпретатор или онлайн‑компиляторы (Replit, Google Colab).

Переменные и ввод

В Python блоки кода выделяются отступами. Переменные создаются присваиванием, ввод — через input(), вывод — через print().

# Пример
name = input("Как тебя зовут? ")
age = int(input("Сколько тебе лет? "))
print(f"Привет, {name}! Тебе {age} лет.")

Задача 1

Запроси у пользователя два числа и выведи их сумму.

Частые ошибки: забывают преобразовать ввод в число (int()), путают + для строк и чисел, не используют f-строки или конкатенацию.

Условия и логика

Условные конструкции if/elif/else и логические операторы and/or/not позволяют управлять потоком программы.

age = int(input("Твой возраст: "))
if age >= 18:
    print("Доступ разрешён.")
elif age >= 13:
    print("Требуется согласие родителей.")
else:
    print("Доступ запрещён.")

Задача 2

Пользователь вводит число. Выведи «Положительное», «Отрицательное» или «Ноль» в зависимости от значения.

Частые ошибки: используют только if, забывая про elif/else; сравнивают строки вместо чисел; пишут условия в неверном порядке.

Циклы

Цикл for перебирает элементы, while работает, пока условие истинно.

for i in range(1, 6):
    print(i)

i = 1
while i <= 5:
    print(i)
    i += 1

Задача 3

Выведи таблицу умножения на число N (вводится пользователем) от 1 до 10.

Частые ошибки: путают границы range(); забывают про шаг; используют while без изменения счётчика (бесконечный цикл).

Функции

Функции объявляются через def, принимают аргументы и могут возвращать результат.

def greet(name):
    return f"Привет, {name}!"

def add(a, b):
    return a + b

Задача 4

Создай функцию is_prime(n), которая возвращает True, если число простое, и False в противном случае. Проверь её на нескольких числах.

Частые ошибки: забывают return; используют print вместо возврата значения; не проверяют граничные случаи (0, 1, отрицательные числа).

Списки и словари

Списки — изменяемые упорядоченные коллекции, словари — пары ключ‑значение.

fruits = ["яблоко", "банан", "вишня"]
fruits.append("груша")

person = {"name": "Иван", "age": 30}
print(person["name"])

Задача 5

Создай список из 5 чисел. Найди максимальное и минимальное значение. Создай словарь с тремя парами ключ‑значение и выведи все ключи.

Частые ошибки: пытаются использовать .keys() на списке; путают индексацию списка и доступ по ключу словаря; забывают, что индексы начинаются с 0.

Файлы и обработка ошибок

Чтение и запись файлов через open() с контекстным менеджером with. Обработка исключений — через try/except.

try:
    with open("data.txt", "r", encoding="utf-8") as f:
        content = f.read()
        print(content)
except FileNotFoundError:
    print("Файл не найден.")

Задача 6

Попробуй прочитать несуществующий файл и корректно обработай ошибку: выведи понятное сообщение, а не технический traceback.

Важно: запись и чтение файлов в браузере не работают из‑за политик безопасности. Выполняй эту задачу в локальной среде (VS Code, PyCharm и т. п.).

Частые ошибки: ловят слишком общее исключение (except Exception) вместо конкретного; не используют with; забывают указать кодировку encoding="utf-8".
